# voltahub-pl

## Wersje językowe

Polska wersja HTML i polskie dokumenty Google są zawsze wersją referencyjną. Angielskie strony w `/en/` utrzymujemy ręcznie jako osobne pliki. Przy każdej zmianie najpierw aktualizujemy polską treść, potem odpowiadające jej angielskie strony, dokumenty Google i PDF-y. Szczegóły i odnośniki do źródeł są w `AGENTS.md`.
